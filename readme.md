# About PRG

Paradigms Research Group (PRG) is a multidisciplinary reading group led by Benjamin Parry and Michelle Jia. We read influential papers across many academic fields and investigate them from the lens of progress. PRG meets every week in downtown Toronto. [Official website is here.](https://www.benparry.ca/prg/)

## About the website
